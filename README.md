🐸 Frog Crossing
Simple 3‑D hopping game made with Three.js.
Move the frog across procedurally‑generated roads/grass while dodging cars and trucks.

Tech: JavaScript, ES modules, Three.js, AABB collision, DOM input.
Controls: arrow keys or buttons; movement is validated/queued.

Structure:
components (player, map, vehicles, lighting), utilities (position math, map gen), plus animatePlayer.js, hitTest.js, script.js, index.html.
